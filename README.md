## 🙋‍♂️ Sobre mim

Atualmente, atuo como **Desenvolvedor Delphi Junior**, focado na criação de novos sistemas *desktop* e manutenção de código. Além disso, tenho implementado soluções de **automação** para otimizar fluxos de trabalho, como o **sistema de chamados de suporte automático com n8n**.
